## Reading the reference

- Each member in a summary links to its full description, and type names link to their own pages.
- Expand an inherited group to browse members from parent classes.
- Common classes have Luau examples. Godot's original examples are folded by language.

**Signatures:**

- `?` marks an optional parameter.
- Instance methods use `:`. Static methods and constructors use `.`.
- Enum parameters show `EnumItem`, and bitfields show `number`. See [engine enums](../luau/enums.md#engine-enums).
