## Reading the reference

Member summaries link to their details. Type names link to local references. Expand inherited groups to browse parent members. Common classes include checked Luau examples; original engine examples remain folded by language.

`?` marks optional parameters. Instance methods use `:`, static methods and constructors use `.`. Enum parameters show `EnumItem`; bitfields show `number`. [Engine enums](../luau/enums.md#engine-enums).
